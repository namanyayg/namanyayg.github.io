Richie

June 2016 · Apps & tools

A budgeting bot I could talk to through chat.

The budgeting logic survives, but I haven’t recovered the chat interface.

Dates & sources

The repository contains 40 commits dated 6 June 2016. The original message handler establishes the budgeting features described here.

I built Richie to track a budget through messages. It could record income and spending, account for recurring expenses, and tell you how much was left for the day or week.

The code connects a Messenger-style webhook to a message handler and a small local database. Forty commits survive from 6 June 2016. The account connection is no longer running.
