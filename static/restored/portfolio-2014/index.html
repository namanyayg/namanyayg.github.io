MakeUseOf

We have worked with Namanyay for nearly a year on a full-time basis. He is a knowledgeable designer with a good eye for user interface and usability matters.

I worked with MakeUseOf from January 2013 – June 2014 as a UI designer and front-end developer. The goal was to redesign the site and create an engaging experience, while keeping social sharing and responsiveness in mind. I worked mainly with Aibek Esengulov, CEO and James Bruce, CTO.

I created a build system based on Gulp, SASS, and Git for a better workflow among other things. A vast number of templates had to be created for the various pages, which had to be backward compatible as well as being inline with the new style’s philosophy.

Coin Market Basket

I’ve had a very positive experience working with Namanyay for CoinMarketBasket. I asked him if the project could be completed in 2 weeks, and 9 days later I sign off on the finished product! Very fast turnaround, polite, and responds to emails quickly.

Coin Market Basket is a one-page table which shows the prices of common goods in all cryptocurrencies.

I was responsible for the design, front-end, and the backend of the site. The backend is a simple PHP script that scrapes CoinMarketCap every day and outputs data to a JSON file. The front-end Javascript then reads said data and arranges it in a table.

Technophilia Podcast

Namanyay is a talented designer who was able to implement all of my crazy ideas skillfully, all within the confines of a tight deadline.

Technophilia Technology (or MakeUseOf TV) is a podcast run by Justin Pot, James Bruce and Dave LeClair of MakeUseOf. It’s Earth’s favorite technology podcast.

Oh, The Things You Can Buy

Namanyay has a great knack for color pallettes and uses a simple minimilistic design style. If you are in need of a responsive, talented, and kind designer, I highly recommend Namanyay.

Oh, the things you can buy, or OTTYCB, is a site that lists cool, fun, and amazing things to buy online. The site is monetized using an affiliate-marketing based model.

I was responsible for the branding, back-end, front-end, and the user interface of the site. I built the site on WordPress , extensively using Custom Post Types and Custom Fields, to make posting as easy as possible for Matthew.

The site is fully responsive and aims to deliver a perfect experience to both mobile and desktop users.

Webstiles

Webstiles is an open-source template for designers to quickly prototype web designs. It allows for easy and rapid prototyping of a site, by defining colors, typography, UI bits, and more.

It’s open source and built by me from scratch, keeping the design-in-browser philosophy in mind. It’s on Github with over 80 stars.

TLDRtech

TLDRtech is a blog by a friend and I with goals to sum up technology articles and allow people to quickly read through them, which started as a weekend side project.

I work on the front-end development and the design of the site, which is built on Node.js’s Ghost CMS. The site features social media and mailchimp integration to increase user interaction.
