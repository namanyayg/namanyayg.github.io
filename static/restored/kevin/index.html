Note: Kevin is currently in Alpha, so please only give him small goals for now.

Kevin (Alpha) interacts with your local filesystem using a websocket connection to pty (that you have to separately install) and writes JavaScript code and Jest tests to write any code that you want. Currently, it cannot read or modify existing codebases.

Since I started freelancing around ~12 years ago, it has been a dream of mine to create a bot that could write code for me (so I could delegate the boilerplate and focus on the creative parts of programming).

Seeing Devin made me realize that my teenage dream is close to becoming reality. For personal satisfaction, I embarked on making my own open-source interface.

The name comes from the legendary phreaker and my childhood hero Kevin Mitnick and is a play on Cognition Labs’ product name.

I have clocked around ~10 hours working on Kevin till now, so please keep the appropriate expectations. I’ve made Kevin for myself as a hobby project and I’m usually actively working on something else.

Tasks:

  • Make a terminal web interface connected to the local filesystem using websocket and node-pty.
  • Make GPT4 work with the terminal using nano, node, and jest.
  • Add a “Planner” agent
  • Set up RAG so it can modify any existing codebase
